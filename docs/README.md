# Project Documentation & Resources

This directory contains visual documentation assets and sample data files for **Grove**.

---

## Directory Layout

```text
docs/
├── README.md               # Documentation guide (this file)
├── sample-data/            # Pre-configured sample JSON files
│   └── acme-tech.json      # Sample company hierarchy with rich properties
└── screenshots/            # Visual application screenshots
    ├── shot_dark.png       # Dark Theme main interface
    ├── shot_light.png      # Light Theme main interface
    ├── shot_search.png     # Real-time search & filter demonstration
    └── shot_copy_feedback.png # Animated JSON Copy feedback
```

## Usage Instructions

- **Testing JSON Import:** You can import `docs/sample-data/acme-tech.json` using the **Import** button in the app to test complex multi-level JSON structures.
